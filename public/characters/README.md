# キャラ素材の置き場所

描き起こしたキャラクターの PNG を**ここに置くだけ**でゲームの絵が差し替わります。
コードの変更は要りません。置いていない姿は、いまのコード生成のドット絵がそのまま使われます。

## 置き方

```
public/characters/manifest.json        ← 使う素材の一覧（これが無いと何も読み込まない）
public/characters/<タイプID>/<姿>.png
```

`manifest.json` の中身は相対パスの配列です。**動く絵**は「コマを横に並べた1枚のPNG」にして、
コマ数（と1秒あたりのコマ数）を書きます。1枚絵と混ぜて書けます。

```json
{
  "files": [
    "m_sporty/walk.png",
    { "file": "m_sporty/swimFree.png", "frames": 3, "fps": 7 },
    { "file": "g_genki/kick.png", "frames": 2, "fps": 7 }
  ]
}
```

コマは**左から順に、同じ幅で**並べます（全体の幅 ÷ コマ数 が1コマの幅）。
読み込んだあとにコマへ切り分けてループ再生します。
**歩きのコマ送りは、その人が実際に動いているあいだだけ進みます**
（立ち止まっている人が足踏みして見えないように）。泳ぎは常に動きます。

一覧に書いたものだけを読み込むので、**描けた素材から順に差し替えていけます**。
書き間違えたファイル名は読み飛ばすだけで、ゲームは止まりません。
起動は**素材を読み終えるまで待ちます**（待たずに始めると、その回に施設へ出た人が
ドット絵のままになってしまうため）。読めないときも4秒で先へ進みます。

## タイプID（20種）

素材シートの並びと同じです（`src/gfx/charTypes.ts` が正本）。

| 区分 | ID | 呼び名 |
| --- | --- | --- |
| 大人 男性 | `m_sporty` / `m_muscle` / `m_student` / `m_office` / `m_senior` | スポーティー／筋トレ好き／爽やか学生／社会人／シニア |
| 大人 女性 | `f_energetic` / `f_cool` / `f_student` / `f_adult` / `f_senior` | 元気系／クール系／学生／大人女子／シニア |
| 幼児 男の子 | `b_genki` / `b_ottori` / `b_yancha` / `b_oshare` / `b_nakimushi` | 元気っ子／おっとり／やんちゃ／おしゃれ／泣き虫 |
| 幼児 女の子 | `g_genki` / `g_ottori` / `g_yancha` / `g_oshare` / `g_nakimushi` | 同上 |

大人タイプは**学童・中高生・大人・一般客**が共用します（体の大きさだけ変わります）。
幼児タイプは幼児クラスだけが使います。

## 姿（ファイル名）

| ファイル名 | 何の姿か | 誰に要るか |
| --- | --- | --- |
| `walk.png` | 立ち・歩き（手前向き） | 全員 |
| `walkBack.png` | 立ち・歩き（奥向き＝背中） | 全員 |
| `suit.png` | 水着の立ち姿（プールサイドで待つ・準備運動） | 幼児〜大人 |
| `swimFree.png` | クロール | 中高生・大人 |
| `swimBreast.png` | 平泳ぎ | 中高生・大人 |
| `swimBack.png` | 背泳ぎ | 中高生・大人 |
| `swimFly.png` | バタフライ | 中高生・大人 |
| `dive.png` | スタート（飛び込み） | 中高生・大人 |
| `train.png` | トレーニング姿（筋トレ・スタジオ） | 中高生・大人・一般客 |
| `kick.png` | ビート板でバタ足 | 幼児・学童 |
| `float.png` | 水に慣れる／浮く基礎練習 | 幼児・学童 |

幼児は四泳法に分けず、`kick` と `float` の2つだけで足ります
（スクールの基礎練習段階、という設計に合わせてあります）。

## 大きさ・原点

**大きさは合わせなくて構いません。** 表示するときに `gfx/charAssets.ts` の
`charAssetScale()` が「**画像の縦＝その人の背丈**」として、体型ごとの背丈
（幼児18／学童21／中高生24／大人27ドット ×3倍）に合わせて縮尺を掛けます。
高い解像度で描くほど、寄ったときに綺麗に見えます（目安は立ち姿の縦80px前後）。

- **上下に余白を入れない**（余白ぶんだけ人が縮んで見えます）。左右の余白は無害です。
- 足元が**下端中央**に来るように描く（立ち位置がここで決まります）。
- 泳ぎ・水中の姿 … 横長（幅 ≒ 高さ×1.5）。**水面が上から約64%**の位置に。
- **向きは「右向き」にそろえる**（歩きも泳ぎも）。ゲームは進行方向で左右反転するので、
  反転していない絵は**画面の右へ進むとき**に出ます。左向きの絵を入れると、
  頭の向きと進む向きが逆（後ろ向きに泳ぐ／後ろ歩き）になります。
- 背景は**透過**。
- 素材は必ず縮小して表示するので、拡大表示（NEAREST）ではなく LINEAR で描画します。

## いま入っている絵（2026-08-15）

**20タイプ × 必要な姿が全部そろっています**（コード生成のドット絵に戻る場面はありません）。
素材シート3枚から切り出したもので、切り分けはツールが行います。

| シート | ツール | 取り出す姿 |
| --- | --- | --- |
| `tools/charsheet.png`（私服） | `python tools/cut_charsheet.py tools/charsheet.png` | `walk`（2コマ）／`walkBack`／`train` |
| `tools/swimsheet.png`（泳ぎ） | `python tools/cut_swimsheet.py tools/swimsheet.png` | 四泳法・`dive`・`kick`・`float`・`swim`（2〜4コマ） |
| `tools/suitsheet.png`（水着） | `python tools/cut_suitsheet.py tools/suitsheet.png` | `suit` |

3つとも `manifest.json` を**自分が書いたぶんだけ差し替えて**書き戻すので、
1枚だけ描き直して流し直せます。シートを描き直したときは `--debug` を付けて
確認画像を出し、スクリプト内の表（`ASSIGN` / `SECTIONS`）の番号・座標を直してください。

動くのは次の姿です。止まっている人は足を止めます。

| 姿 | コマ数 |
| --- | --- |
| 四泳法・潜る浮上・バタ足・浮き輪 | 2〜4コマ（常に動く） |
| `walk`（私服の歩き） | 7タイプが2コマ、残り3タイプは1枚 |
| `walkBack` | f_cool / f_student が2コマ、残りは1枚 |
| `suit`・`train` | 1枚 |

**代用しているところ**（シートに無かったぶん）:

- 幼児の背面（`walkBack`）… 正面の絵を流用
- 学童の `kick` / `float` … 大人タイプにはバタ足の絵が無いので、クロール／平泳ぎで代用
- `train` の m_office / m_senior / f_adult … シートの絵はマシンごと描かれていて
  施設のマシンと二重になるため、立ち姿で代用
- m_sporty の `walkBack` … 背面が無いので横向き

**コーチ・受付スタッフは別の絵**（`gfx/textures.ts` の `staffKey`）なので、
このフォルダの素材では差し替わりません。いま画面でドット絵に見えるのはこの2種類だけです。

## 確認のしかた

```
npx esbuild charcheck.ts --bundle --platform=node --format=esm --outfile=tmp.mjs && node tmp.mjs preview.html
```

`preview.html` に全タイプ・全姿が並びます（コード生成の絵のプレビュー）。
実際の画面での見え方は `?dev=facility&full=1` で確認できます。
