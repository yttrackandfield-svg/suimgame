# 切り出し座標の表（アトラス）

`atlas.ts` は、**スプライトシートのどこに・誰の・どの向きの・何コマ目があるか**を書いた表です。
ゲームはシートを1枚のまま読み込み、この表の座標で切り出します。

**コマがズレていたら、ここの数字だけ直せば直ります**（画像を作り直す必要はありません）。

```
assets/characters/atlas.ts          ← 座標の表（人が直す）
public/characters/sheets/*.png      ← ゲームが読むシート（背景を透過させたもの）
tools/coach_*.png                   ← 元のシート（透過前。ツールの入力）
tools/cut_coachsheet.py             ← 表とシートを作り直すツール
```

## 座標の書き方

```ts
walk: {
  down: { f: [[246,124,29,64], [285,124,29,64], [321,124,29,64]] },
  right: { f: [[508,124,27,62], ...], flip: true },
}
idle: [1270,147,44,106]
```

- `[x, y, 幅, 高さ]`。元のシートの中の位置です。
- **1つの向きのコマは同じ大きさ**にしてください（違うと歩くたびに伸び縮みして見えます）。
- **足元が四角の下端中央**に来るようにしてください（立ち位置がここで決まります）。
- `flip: true` は「絵が左を向いているので、右へ進むときは左右反転して使う」印です。

## 向きの決まり

ゲームは**反転していない絵＝画面の右へ進む**として扱います。
等角なので、マスの軸と画面の向きは45度ずれます。

| マスの動き | 画面の向き | 使う絵 |
| --- | --- | --- |
| +gx | 右下 | `downRight` |
| +gy | 左下 | `downLeft` |
| −gx | 左上 | `upLeft` |
| −gy | 右上 | `upRight` |
| +gx+gy | 真下 | `down` |
| −gx−gy | 真上 | `up` |
| +gx−gy | 右 | `right` |
| −gx+gy | 左 | `left` |

## 作り直すとき

```
python tools/cut_coachsheet.py --debug
```

- `tools/coach_normal.png` / `tools/coach_pro.png` を読み、
  `assets/characters/atlas.ts` と `public/characters/sheets/*.png`（透過版）を書き出します。
- `--debug` を付けると `tools/vis_*.png` に赤枠つきの確認画像が出ます。
- シートの並びが変わったときは、ツールの `DIRS`（ラベルの順）と
  `FLIP_RIGHTWARD`（そのシートの右向きが左向きに描かれているか）を見直してください。

## いま入っているもの

- コーチ 10パターン（通常5・上級5）× 8方向の歩行（通常＝3コマ／上級＝2コマ）＋ 待機
- 割り当ては `src/gfx/coachSprites.ts`。**格1〜3＝通常／格4〜5＝上級**、
  どのパターンになるかはコーチのIDで決まる（同じコーチはいつも同じ見た目）。

選手・一般客の絵は別の仕組みです（`public/characters/<タイプID>/<姿>.png` に
切り出し済みのPNGを置く方式。→ `public/characters/README.md`）。
